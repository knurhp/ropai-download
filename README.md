# ROP AI downloads

Get the latest version from **[Releases](https://github.com/knurhp/ropai-download/releases/latest)**. The files are password-protected; ask the person who sent you this link for the password.

- **macOS (Apple Silicon):** open the `.dmg`, enter the password, and drag **ROP AI** to **Applications**. The first time, Control-click the app and choose **Open** (on newer macOS: **System Settings → Privacy & Security → Open Anyway**).
- **Windows (x64):** right-click the `.zip`, choose **Extract All**, enter the password, and extract it to a folder in your user profile. Run `ROP AI.exe` inside. If SmartScreen warns, choose **More info → Run anyway**.

Once installed, ROP AI updates itself; the password is only needed for this first download.
